### v7 的核心突破

S00 原来用关键词判"是否重述"，2,157 份标"待核"。回原文核实后发现两个误判来源：

1. **合并所有者权益变动表的固定行**「加：会计政策变更 / 前期差错更正 / 其他」——每份都有
2. **会计政策变更 ≠ 差错更正**——年报「重要事项」里两项紧邻，多数公司（一）是"√适用"
   （标准仓单交易、准则解释第19号），（二）才是"√不适用"

最终判据改用**附注「未分配利润」调整明细**（会计准则强制披露）：

```
3、由于重大会计差错更正，影响期初未分配利润 0 元。
4、由于同一控制导致的合并范围变更，影响期初未分配利润 0 元。
```

金额为 0 即未发生。1,007 份结论：**明确无重述 962、确认有重述 3、宽容假设 42**。
