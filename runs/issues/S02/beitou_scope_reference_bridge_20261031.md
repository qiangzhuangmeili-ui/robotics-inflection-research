## 2. 机械剔除情景（仅敏感性参考）

2026H1报告第6—7页披露：
- 2025H1调整后集团营收：2,040,688,597.65元；
- 2025H1调整前集团营收：577,992,118.41元；
- 2026H1本期营收：1,412,590,656.59元；
- 报告明确：调整后比较期包含置出资产广电科技及置入资产交科集团1—6月经营业绩；2026H1本期不包含广电科技。

机械情景：`2,040,688,597.65 − 551,151,700.00 = 1,489,536,897.65元`。
以此作为参考基数，2026H1营收同比约为`-5.1658%`；报告调整后口径同比为`-30.7787%`。两者相差约25.61个百分点。

**该-5.17%不是正式持续经营同比，也不能写入正式M01。** 551,151,700元是广电科技子公司层面披露的单体营业收入，不等于置出资产在上市公司合并报表中的外部收入贡献。

## 3. 利润数据只能作为旁证

广电科技2025H1子公司层面净利润为-334,745,300元；2025H1调整后集团归母净利润为-299,249,942.67元。机械相减得到约+35,495,357元的残差，但两者并非完全相同的会计口径（集团归母 vs 子公司净利润），不得计算增长率，也不能代替扣非归母净利润。
- 广电科技子公司营业利润：-337,825,300元；
- 广电科技子公司扣非归母净利润：未披露；
- 广电科技子公司经营活动现金流净额：未取得。

因此M05/M06/M09仍不能建立同范围正式比较。

## 4. 为什么不能把子公司收入直接当作集团贡献

2025H1报告未审计；其第13页只提供主要子公司财务数据，没有给出广电科技在上市公司合并报表中的外部收入贡献、内部交易抵销表或完整子公司现金流/扣非数据。报告的关联方及关联交易附注还列示了广电科技相关业务链的采购、销售及服务交易，说明子公司单体数据不能直接替代合并口径贡献。

2026H1报告也明确说明：2025H1调整后比较期同时包含广电科技与交科集团1—6月经营业绩，而2026H1本期不再包含广电科技。会计追溯调整解决了同一控制合并的列报问题，但没有自动生成“剔除广电科技后的持续经营比较数”。

## 5. 追索决策

**建议：当前不继续投入高成本追索，暂缓至候选短名单阶段。**

理由：
1. 已有公开子公司数据足以判断置出资产规模大、亏损重，并说明原始同比受范围变化显著影响；
2. 公开数据不包含集团合并抵销后的完整收入、成本、扣非和现金流贡献；
3. 即使获得子公司单体报表，也仍需内部交易抵销及集团层面的持续经营备考口径；
4. 该工作成本较高，不适合全池第一轮筛选。

- M04/M06/M09继续参考或HOLD；M05普通同比不定义；M02/M03/M07和M10—M12继续HOLD；
- M08仅保留本期现金含量指标。

若北投科技进入重点候选短名单，再向IR索取：广电科技2025H1在上市公司合并层面的贡献（含其下属主体）、与上市公司/交科集团/其他子公司的内部交易抵销后收入和成本、扣非利润、经营现金流，以及同期间追溯后资产负债表。未取得前不解除HOLD。
