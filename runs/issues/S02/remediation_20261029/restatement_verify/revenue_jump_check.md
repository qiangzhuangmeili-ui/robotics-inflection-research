# 35 家营收异动核查结果（2026-10-30）

## 方法

对每家取最新期报告（半年报/年报），定位「营业收入变动原因说明」段落，
看是否明确提到合并范围变更（并表、收购、置出、处置）。
**不看会计政策章节**（那里全是「同一控制/非同一控制」的方法论模板，会大面积误判）。

## 结果：7 家确认是并表/处置导致，28 家未见并表说明

### A. 并表或处置导致（7 家）——同比不可比

| 公司 | 营收同比 | 原因（原文） |
|---|---|---|
| 顺景科技 603007 | +1662.3% | 2025-08 完成对尼威动力控股权收购，纳入合并范围 |
| *ST京化 600889 | +243.7% | 重大资产重组，置入南京工艺（滚动功能部件） |
| 北投科技 600936 | +144.4% | 同一控制下企业合并，上年同期追溯调整 |
| 美力科技 300611 | +131.7% | ACPS 第二季度经营业绩纳入合并报表 |
| 雅创电子 301099 | +118.7% | 原文只说「营收快速扩张」，**未明确并表**，需人工确认 |
| 奔图科技 002180 | -63.0% | 合并范围变更，本期**不包含已处置子公司**收入 |
| 日发精机 002520 | -56.7% | Airwork 及 MCM **不纳入合并范围** |

**这 7 家的营收同比不能直接用于判断「改善」**：
- 前 5 家是并表带来的增量（不是内生增长）
- 后 2 家是处置带来的减量（不是经营恶化）

但**「未见并表说明」不等于「一定没有并表」**——有些公司可能只在附注披露、没在管理层讨论里写。

## 三、建议

1. **7 家（A 类）**：S03 筛选中标「口径待核」，营收同比不作为改善证据。
   其中雅创电子需人工确认是否并表。
2. **28 家（B 类）**：可以正常参与筛选，但 S03 缩圈后建议抽查附注的「合并范围变更」章节。
3. **江波龙**单独注意：有收购 Zilia 81% 股权和元成苏州 70% 股权，形成 8.30 亿商誉，
   虽然管理层讨论没写「营收增长因并表」，但需要确认。
