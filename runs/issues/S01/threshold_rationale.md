# S01 阈值理由登记 v1

- 规则版本：`S01_SCREEN_RULES_V1`；对应公式见 `metric_formulas.md`
- 核心立场：**阈值是研究假设，不是行业定律**。本版全部阈值先验给定，未用当期分布拟合，也未看任何公司结果。
- 冻结顺序：先写规则 → 记输入指纹 → 再允许匿名分布统计（探索性、不回头改 v1）

---

## 一、为什么是这些数

| 编号 | 阈值 | 取值 | 为什么是这个量级 | 可能错在哪 |
|---|---|---|---|---|
| T1 | 营收同比 ≥ **10%** | SG01 | 高于名义 GDP 增速与制造业平均，才谈得上「快于大盘」；低于 10% 的波动更像价格/口径噪声 | 高增长细分（如人形机器人零部件）10% 偏松；成熟集成商 10% 偏紧 |
| T2 | 单季加速 ≥ **5pp** | SG02 | 单季同比本身噪声大，5pp 以下常由基数或交付节奏造成，不足以称「加速」 | 项目制公司单季交付跳跃会让加速度虚高，需 L2 用累计口径复核 |
| T3 | 毛利率 +**1.0pp** | SG03 | 1pp 是财报可辨识的最小经济变动；低于 1pp 通常在四舍五入与产品结构微调范围内 | 原材料价格大幅波动年份，1pp 可能只是成本滞后 |
| T4 | 扣非同比 ≥ **20%** | SG04 | 约为营收门槛的 2 倍，要求利润增速快于收入，隐含经营杠杆改善 | 低基数年份 20% 很容易达到，故叠加 Q05 低基数规则 |
| T5 | 扣非净利率 +**1.0pp** | SG05 | 与 T3 对齐，衡量「赚得更有效率」而非「赚得更多」；可捕捉收入持平但结构改善 | 费用一次性下降也会推高，需 Q09 一次性标记辅助 |
| T6 | 扣非转正且 ≥ **1,000 万元** | SG06 | 亏损收窄到微利不构成拐点；1,000 万是对 1,054 家池子中位体量有意义的绝对额 | 小市值公司 1,000 万可能过高，故仅作 PROFIT 维度一条，不单独定生死 |
| T7 | OCF/归母 ≥ **0.8** | SG07 | 0.8 允许合理的营运资本占用，低于 0.8 说明利润未转化为现金；同时要求 M09>0 | 快速扩张期公司现金流天然偏低，会漏掉「增长但暂时吃现金」的标的 |
| T8 | 现金流转正 | SG08 | 从负到正是质变，比「改善幅度」更稳健；不受基数大小影响 | 一次性回款（如大额预收）也会转正，需 L3 看附注 |
| T9 | 单季扣非 ≥ **30%** | SG09 | 单季口径噪声更大，门槛高于累计的 20%，降低假阳性 | 单季确认收入的公司会大幅波动，需与 M01 累计口径交叉 |

**方向约定**：毛利率、扣非同比、扣非净利率、现金含量为「越高越好」；应收/存货周转天数为「越低越好」，因此风险提示用 `≥ +30 天`；合同资产占比方向中性，只作风险提示（RH03），不当作改善。

## 二、两层筛选的错误成本不对称

| 层 | 目标 | 允许的错误 | 阈值取向 |
|---|---|---|---|
| L1 宽筛（S03） | 不漏掉可能的拐点 | 容忍假阳性 | 单条信号即可进观察队列；宁可多留 |
| L2 收紧（S04/S05） | 少留噪声 | 容忍假阴性 | 要求 ≥2 个维度同时改善 + 数据质量闸门 |

因此同一指标在两层使用同一阈值，但**组合规则不同**：L1 是「或」，L2 是「且」。这样不会出现「为了 L2 好看去改 L1 阈值」的动机。

**没有目标家数**：本规则集不含 `target_count` / `quota` / `top_n`，L1 输出可以是 0 家也可以是 900 家；数量由数据决定，不由研究者的预期决定。

---

## 三、为什么不做当期分布拟合

1. **循环论证**：用筛选结果反推阈值，再宣称筛选有效，等于自己证明自己。
2. **截面不完整**：2026Q3 只有 188/1,054 家已披露，用当期分布定阈值会把「披露早」当成「基本面好」。
3. **不可复现**：分布随披露进度每天变化，阈值若随之漂移，任何历史结论都无法复算。

因此 V1 采用**先验假设 + 最小经济意义**，并把「阈值是否过松/过紧」留到 S02 之后用匿名分布描述，而不是回头改 V1。

## 四、探索性匿名校准（允许，但不具约束力）

- **时点**：规则冻结、指纹写入 `manifest.json` 之后
- **允许的输出**：各指标 P10/P25/P50/P75/P90 分位、各信号命中家数、各质量标记计数
- **禁止的输出**：公司名称、可反推个体的明细、按信号排序的名单
- **效力**：仅用于说明「阈值卡在分布的什么位置」，**不得据此修改 V1**；若要改，另立 `screen_rules_v2.json` 全池重算并出差异报告
- **记录位置**：`metric_coverage_dryrun.csv`（仅聚合计数）与本文附录

## 五、亏损、缺失与低基数为什么这样处理

| 情形 | 处理 | 理由 |
|---|---|---|
| 扣非为负、亏损扩大 | 不算同比，记 `RISK_LOSS_WIDENING`，不剔除 | 亏损本身不是淘汰理由；拐点常出现在亏损收窄阶段，剔除会系统性漏掉早期标的 |
| 扣非由负转正 | 用 SG06 绝对额门槛，不用百分比 | 负基数下百分比无意义（−100 万到 +100 万是「−200%」） |
| 归母 ≤ 0 | 不算 OCF/归母 | 分母为负会让「现金含量」符号反转，产生假改善 |
| 营收 ≤ 0 或 < 100 万 | 不算任何比率 | 分母趋零时比率爆炸，属数值伪影 |
| 基期营收 < 5,000 万 / \|扣非\| < 1,000 万 | 信号标 PROVISIONAL | 低基数下 20% 增长可能只是 200 万绝对额，不构成经营拐点 |
| 数据缺失 | MISSING，不填 0、不插补 | 填 0 会把「不知道」变成「很差」；插补会把同业情况伪装成公司事实 |
| HOLD（xcheck 不一致等） | 指标 HOLD，不算改善也不算恶化 | HOLD 是「证据不可用」，不是「结论为否」 |
| 重述未决 | 指标 PROVISIONAL，不进 L2 | 跨期口径不一致时，「改善」可能只是重述造成的账面变化 |
| 上市前 / 无上年同期 | NOT_COMPARABLE，进 W4 | 没有可比期就没有同比，任何「增长」都是编的 |
| 项目制 vs 设备制 | 项目制不看存货天数 | 项目制的存货/合同资产结构不同，用设备制周转天数会误判 |

## 六、变更程序

1. 任何阈值、公式、缺失处理的变化 → 新建 `screen_rules_v2.json`（v1 只读保留）
2. 必须写明：改了什么、为什么改、影响哪些指标、预期影响面
3. 全池重算，输出 v1 vs v2 差异报告（家数、进出名单、变动原因）
4. **禁止**手工把个别公司加回名单；禁止只对个别公司重算
5. 版本号、冻结时间、输入指纹三者必须同时登记，缺一不可复算

---

## 七、本版已知局限（须随结论一起引用）

1. 阈值全部为先验假设，未做行业分组校准（机器人本体 / 零部件 / 集成 / 物流自动化 的合理增速不同）
2. 未区分下游行业景气差异，10% 对 3C 与对锂电设备含义不同
3. 单季口径依赖 S00 的单季来源优先级（官方分季表 > Q1 即单季 > 累计相减），累计相减的 8,239 格精度低于分季表
4. 2026Q3 截面不完整（188/1,054），当期横截面结论只能作参考
5. 旧快照 2021/2022 为单一来源，涉及这两年的同比带 `SINGLE_SOURCE` 标记
6. 62 个整槽无值公司（英 26 / 无文本层 14 / 盲区 20 / 混排 2）在 W1 名单，不代表其基本面

信号命中（可重复计数）：SG01 460、SG02 522、SG07 232、SG03 307、SG05 244、SG04 224、SG09 203、SG08 97、SG06 35。
分层干跑：L1 观察队列 867（82.3%）/ 仅风险提示 120 / 无信号 67；L2 收紧 290（27.5%）/ 未入选 706 / 数据不足 HOLD 58。

**观察到的两个问题（记录，不修改 v1）**：

1. **SG01 ∪ SG02 覆盖 718 家（68%）**：单季加速 5pp 在收入确认不均匀的公司里极易触发，宽筛通过面偏大（L1 合计 82%）。
2. **L2 两维组合干跑 290 家（27.5%）**：MARGIN 与 PROFIT 都来自利润率，计入两个维度仍属重复计数。

**为什么不在本版改**：一旦看到分布再改阈值，就变成用结果校准规则，违反本卡「先登记、后运行」的目的。正确做法是在 S04 收紧前另立 `screen_rules_v2.json`，明确写清：
- 维度独立性要求（≥2 维中至少 1 维来自 GROWTH 或 CASH）
- 单季加速门槛由 5pp 上调（需给出与交付节奏无关的理由）
- 全池重算并出 v1/v2 差异报告

本附录的数字**不得**被引用为「有多少家改善」或任何名单结论；它们只证明规则可执行。
