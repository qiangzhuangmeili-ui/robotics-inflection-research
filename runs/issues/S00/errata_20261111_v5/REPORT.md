## 一、第十五轮裁决的逐条落实

两处不通过的共同点是同一个毛病：**该说的没说到位**——B 把「解析不出」翻译成「可以按语义类证明等价」，

### 1.1 B 项：`_date_span()` 扩写，且无法解析不得放行

裁决实测仍被判等价的四组（含三组指定用例）：

| 左列头 | 右列头 | 根因 |
|---|---|---|
| 本期金额（2026年上半年） | 本期金额（2026Q2） | `_date_span` 不认「上半年 / Qn」 |
| 本期金额（1-6月） | 本期金额（4-6月） | 不认不带年份的月区间 |
| 本期金额（2026年上半年） | 本期金额（2026年4-6月） | 一侧不认，退回语义类 |
| 本报告期 / 本期金额（裸写法） | — | 两侧都解析不出，退回语义类后等价 |

两处改动：

- `_date_span()` 由「年+月区间 / 年月日 / 年月」扩到 **7 种写法**：
  `年+月区间`、`不带年的月区间`、`上半年 / 半年度 / H1`、`下半年 / H2`、`Qn`、`第n季度`、`年月日 / 年月`。
  另加 `_loose_year()`：列头没「年」字时抓 4 位年份（`2026Q2`）。
- **新增「无法解析不得放行」分支**：一侧解析出区间、另一侧写着期间线索（`_RE_PERIOD_HINT`：年/月/季度/Qn/上半年/
  年初/年末/期末/期初/本期/上期/同期/累计）却解析不出 → **直接判不等价**，不再退到语义类。
  这是裁决那句「不能让『无法解析已明确写出的期间』转化为『可以按语义类证明等价』；无法确认时应保留待核」的落地。

16 组配对实测全对（含点名三组全部 `False`）：

```text
本期金额（2026年上半年） | 本期金额（2026Q2）      -> False  ('H1',2026) vs ('Q',2026,2)
本期金额（1-6月）        | 本期金额（4-6月）       -> False  ('R0',1,6)  vs ('R0',4,6)
本期金额（2026年上半年） | 本期金额（2026年4-6月） -> False  ('H1',2026) vs ('R',2026,4,6)
```

C37 断言由 **3 同义 + 8 异义** 增至 **4 同义 + 11 异义**，新增的三组异义就是上表前三行。

**为什么还要加一组同义**：只加异义的话，「一律判不等价」这种退化实现也能全过。
所以各种写法必须**先归一到同一个坐标系再比**：上半年→1–6 月、下半年→7–12 月、`Qn`/第 n 季度→3n-2..3n 月；
没有年份的写法用 `R0` 与带年份的 `R` 区分（年份不确定就不能认同一列）。
新增的同义断言 `本期金额（2026年1-6月）` / `本期金额（2026年上半年）` 就是这条归一规则的证明——
同一段用两种写法，必须仍判等价。

归一后 20 组配对实测 19 对（另 1 对 `4-6月` / `2026Q2` 属**故意**判不等价：一侧没年份，不能替它认定是哪一年）。

**尚未覆盖的残余**（已写进 `open_findings`）：两侧都写了期间、但都落在 7 种写法之外时，仍会退到语义类。
第十五轮只堵住「一侧解析出、另一侧写着线索却解不出」这一种，不是全量覆盖。

## 二、第十四轮裁决的逐条落实

第十四轮裁决的结论是：**F 通过**，A、B、C、H 不通过。
这一轮四处里有三处是**上一轮修的同一个病又犯了一次**：
窗口限了字数（A）、测试跑的输入形式与实际路径不同（C）、判据只改了「说什么」没改「写什么」（H）。
只有 B 是新的口径问题——语义类再细也说明不了「哪一段」。

### 1.1 A 项：影响动词改分句级窗口，不再限 24 字

裁决给的漏判：

```text
…影响0.00元，调减与以前年度销售折让及客户往来余额差异相关的应收账款100.00元  → affirmed=set()
```

第十三轮把动词从「剥完的中心语」挪到「未剥离窗口」，方向对了，但**窗口仍限 24 字**，
而这句话动词距金额 27 字，被截掉后照样判成新主语。

- 影响动词是**分句级属性**（这一句在说「调减某项目」），不是金额的局部修饰语。
  新增 `_effect_win()`：从「上一笔金额结束」到本笔金额，**不设字数上限**。
- 中心语仍用 `_seg()` 的 24 字窗口——那里要的正是「紧邻的名词」，远了不该算。
  两个窗口职责不同，不能共用一个参数。
- 反例 44 → **45 条**（㉗）。

### 1.2 B 项：栏目判定加「区间优先」

裁决实测四组全被判等价：

| 左列头 | 右列头 |
|---|---|
| 本期金额（2026年1—6月） | 本报告期金额（2026年4—6月） |
| 本期金额（2026年1-6月） | 本期金额（2026年4-6月） |
| 期末余额（2026年6月30日） | 年末余额（2025年12月31日） |
| 上年同期（2025年1—6月） | 上年同期（2025年4—6月） |

语义类只能说明「这是本期 / 上年同期」，**说明不了「哪一段」**。
列头自己写着区间，就不该用类别覆盖它。

- 新增 `_date_span()`：识别 `1—6月` / `1-6月` / `6月30日` / `2026年6月` 三种写法。
- `cols_equivalent()` 的判定顺序改为：① 两侧都有区间 → **区间必须相同**；
  ② 否则比语义类；③ 再否则退回子串。
- 「本报告期 / 本期金额」**从同义断言里撤掉**——没有区间时把它当同义是惯例，不是可证事实
  （中报里两者可能分别是 6 个月与 3 个月）。它改到异义表，由区间判。
- C37 断言：**3 组同义 + 8 组异义**（原 4 + 4）。环数仍 35。

### 1.3 C 项：SELF_PAGE 的同行判据在真实路径上失效

裁决给的关键一步：`self_page_line_ok` 本身是对的，但**调用点先对整页 `_nz`**：

```python
_pt = _nz(pages[pg - 1])          # ← 换行被删光
self_page_line_ok(_pt, amt, _names)
```

`_nz` 删除全部空白（含换行），于是

```text
页眉合计 100.00
营业收入 200.00
```

两行拼成一行，同行限制当场失效——**测试跑的输入形式与实际路径不同**，这正是上一轮
「自证失效」的同一个病。另外金额用裸子串匹配，`100.00` 会命中 `1100.00`。

- 调用点改传**原始页文本**，归一化下沉到函数内部逐行做；
- 新增 `_amt_in_text()`：金额左右不得接数字/小数点；
- 金额匹配用**原始行**（保留空白），指标名匹配用归一化行——
  否则归一化会把 `100.00 100.00` 拼成 `100.00100.00`，边界判据反过来误伤第二个金额；
- C24 的 `self_page_ok` 直测从 3 条扩到 **7 条**，且全部按**实际调用形式**（原始页文本）跑：
  页眉/目标行分行、`1100.00` 不命中 `100.00`、制表符与多空格同行仍须认可。

### 1.1 A 项：影响动词改为唯一词表，并改在未剥离的窗口上判

**裁决指出的两处漏判**（都给的是真实语料）：

```text
前期差错更正对期初未分配利润影响0.00元，影响净增加100.00元      → 实测 affirmed=set()
前期差错更正对期初未分配利润影响0.00元其中营业总收入100.00元    → 实测 affirmed={'ERRATA'}
```

第一处的根因不是「词表少一个词」，而是**同一个概念写了两份词表**：
`_TAIL_STRIP`（剥词用）里有「净增加」，`_RE_EFFECT_VERB`（判据用）里没有，
于是「影响净增加」被剥成「影响净」→ 中心语非空 → 判成新主语。

- 现在只有一处 `_EFFECT_WORDS`（21 个词），`_TAIL_STRIP` 与 `_RE_EFFECT_VERB` 都从它派生。
  补词不解决问题，**两份词表才是问题**。
- 第二处：`_head_noun(start=prev_end)` 只在「上一笔金额结束位置」之后找中心语，
  前一笔记账数字不再把主语带歪。

**裁决同时指出 `tgt` 的理由不成立**：「同分句里金额无论属于哪个项目都能证明事件发生」
——这句话确实站不住，已**撤回**。现在的判法（与代码一致）：

| 中心语情形 | 处置 | 依据 |
|---|---|---|
| 空 / 只剩功能词 | 绑定该原因 | 没有新主语，是续写 |
| 受影响权益项目（期初未分配利润等） | 绑定 | 原因的作用对象 |
| 原因短语本身 | 绑定 | 同义反复，但不算换主语 |
| 窗口内出现影响动词（调减/冲减/影响/净增…） | 绑定 | 事件对该项目的作用**结果** |
| 只剩一个裸项目名（「其中某某项目100.00元」） | **不绑定** | 只是余额列举，不是事件证据 |

**返工时又发现一处死代码**（Codex 未点名，属自查）：`_RE_EFFECT_VERB.search(head)` 判的是
**剥完的中心语**，而剥词的职责恰恰是把影响动词剥掉——这段分支永远为 False。
实测 `…影响0.00元，其中应收账款调减100.00元` 仍被拒。
现已抽出 `_seg()`（未剥离窗口），`_head_noun` / `_new_subject` / `_bind_amount` 共用同一窗口，
影响动词一律在 `_seg()` 上判。

反例集由 38 条增至 **44 条**（㉑–㉖）：

| 编号 | 文本 | 期望 |
|---|---|---|
| ㉑ | `…影响0.00元，影响净增加100.00元` | affirmed |
| ㉒ | `…影响0.00元其中营业总收入100.00元`（无逗号） | 空 |
| ㉓ | `…影响0.00元，调减营业总收入100.00元` | affirmed |
| ㉔ | `…影响0.00元，其中应收账款调减100.00元` | affirmed |
| ㉕ | `…影响0.00元，净增100.00元` | affirmed |
| ㉖ | `…影响0.00元，其中应收账款确认金额：300.00元` | 空 |

### 1.2 B 项：期间语义类由 4 类拆 7 类，跨类一律不认

裁决实测：`上年同期 / 上期`、`本年累计 / 本期数` 被判等价——混同了同比期间与紧邻上期、
累计数与单季度数。原 4 类（`PRIOR_YEAR_SAME / YEAR_OPEN / PERIOD_END / CURRENT`）确实过宽。

拆成 7 类：`CURRENT_YTD / PRIOR_YEAR_YTD / PRIOR_YEAR_SAME / PRIOR_PERIOD / YEAR_OPEN / PERIOD_END / CURRENT`，
**两侧都能归类时必须同类**，不再退回子串比较（子串比较是「上年同期」与「上年同期累计」
互认的来源）。

实测 10 组配对：

| 配对 | 结论 | 类 |
|---|---|---|
| 本期发生额 / 本期数 | 等价 | CURRENT |
| 本报告期 / 本期金额 | 等价 | CURRENT |
| 期末 / 年末 | 等价 | PERIOD_END |
| 期初 / 年初数 | 等价 | YEAR_OPEN |
| 上年同期 / 上年同期数 | 等价 | PRIOR_YEAR_SAME |
| **上年同期 / 上期** | **不等价** | PRIOR_YEAR_SAME / PRIOR_PERIOD |
| **本年累计 / 本期数** | **不等价** | CURRENT_YTD / CURRENT |
| **年初至报告期末 / 本期数** | **不等价** | CURRENT_YTD / CURRENT |
| **本期 / 上年同期** | **不等价** | CURRENT / PRIOR_YEAR_SAME |

这 4 组同义 / 4 组异义由 C37 的两条环 `column_synonym_ok` / `column_antonym_rejected` 消费。
**环数仍 35，没有新增环**：这两条环上一轮就在，变的是它们背后的**期间语义类口径**（4 → 7 类）；
本轮新增的只是把配对清单本身写进 detail（`column_synonym_pairs` / `column_antonym_pairs`），
让复核方看到测的是哪 8 组——上一轮这一层不可见。

### 1.3 C 项：小数表号、章节号、以及「无词坐标时页眉冒充目标行」

裁决实测三处绕过：

```text
2025年上半年营业总收入见表格1.2      → 1.2 被当数量
2025年上半年营业总收入参见表3.1      → 3.1 被当数量
2025年上半年营业总收入参见12.1节     → 12.1 被当数量
```

两处原因，都不是「正则少一条」：

1. `_RE_PAGE_REF` 只认「第12页」「见3表」「附表2」这类整数编号，小数形式的表号/章节号
   整个不在覆盖范围。现补 `表|图 + 格? + 编号`、`编号 + 节/章/条/项`、
   `见/参见/详见/参阅 + 编号`。
2. 判定窗口 `seg = frag[start-6 : end]` **截到金额为止**，`参见12.1节` 的「节」被截掉，
   于是「12.1 后面跟节」这条线索永远看不见。现改为尾部多留 4 字。

SELF_PAGE 无词坐标路径：原实现退化为「该金额在本页出现过」，页眉的 100.00 可冒充目标行的 200.00。
现改为 `self_page_line_ok()`——**同一文本行内**同时出现指标名与该金额才算。

**并且**：`literal_path_ok` 与 `self_page_ok` 上一轮只是算出来写进 detail、**没有进任何 PASS 条件**，
汇报却拿 `literal_path_ok=True` 当证据。现在两者都是 C24 的 PASS 条件之一。

### 1.4 F 项：C31 改从 CSV 独立重算，R6 结论按 BOTH/ONE/NONE 条件化

### 1.5 H 项：C39 三步自证，回退不再被自己的写入掩盖

裁决实测：注入旧 checks 字符串后整链仍 PASS。根因是**顺序**——`write_status()` 先跑，

1. **写前**读盘并检查（结构性回退必须报出来）；
2. `write_status()` 写入；
3. **写后**读回校验，并在内存副本上注入三份旧内容自证检查函数有牙。

和「版本号陈旧」（写者本来就该修掉的状态）合成一个原因，于是版本一升，写前检查就把
上一版自己的产物当成回退。现拆成 `SELF_CHECK_POINTER_INCOMPLETE`（结构）与
`SELF_CHECK_POINTER_STALE`（版本），后者归入 `_VERSION_ONLY`。

## 四、第十二轮裁决的逐条落实

第十二轮裁决的结论是：**G 项通过**，A、B、C、D、E、F、H 七项不通过。
与上一轮不同的是，本轮七项里有六项**不是「判据不够严」而是「判据判错了方向」**——
Codex 每一处都给了真实语料上的反例，不是合成语料。

### 1.1 A 项：极性「新主语」改按中心语判，并承认判据确实会触发

上一轮用「金额左侧 10 字以名词收尾」判新主语，Codex 用三句话打穿：

| 输入 | 上一轮判定 | 应为 | 原因 |
|---|---|---|---|
| `…其中营业总收入金额为100.00元` | 续写 | 新主语 | 词尾是「为」，被当成功能词 |
| `…其中营业总收入确认的金额100.00元` | 续写 | 新主语 | 词尾是「金额」，被当成计量单位 |
| `…其中营业总收入合计100.00元` | 续写 | 新主语 | 词尾是「合计」，被当成汇总词 |
| `…影响0.00元，影响增加100.00元` | 新主语 | 续写 | 词尾是「增加」，被当成动词 |

改为**取中心语**：用闭集功能词/动词/量词表（`_TAIL_STRIP`）从右往左反复剥离，
剩下的名词片段即中心语；中心语属权益项目（`_RE_SCOPED_ITEM`）/原因短语（`_CAUSE_ANY`）/
治理参与方（`_RE_PROCEDURE`）/空 → 判续写，否则判新主语。四条反例分别记为 ⑯–⑲，
另加 ⑳ 守护「同分句原因就近命中时不按 new_subj 否定」。

**关于 `tgt` 分支**：上一轮汇报说「已给 `tgt` 分支也加了 `new_subj`」，实际代码没加。
本轮明确：**这是有意的，不加**——`tgt` 表示本分句内原因词就近命中，此时金额无论挂在
哪个项目上都能证明该事件发生；`new_subj` 只约束 `single` / `prev_causes` 两条跨分句继承分支。
docstring 第 6 条写明了这个区别，汇报也改成与代码一致。

**关于「从未触发」**：上一轮汇报写「新判据在真实证据上从未触发」，Codex 插桩显示
`_new_subject` 被调用 88 次、判真 44 次，该说法无据。本轮把计数器直接打进
`replay_polarity_v5.json`，当前值：

```
documents 1007 / clause_changed 0 / polarity_changed 0
new_subject_calls 88 / new_subject_true 0 / new_subject_true_nonzero 0
head_nouns {"附注：由于重大会计差错更正影响期初未分配利润": 44, "同一控制合并范围变更": 44}
```

即：判据在 1,007 份存量证据上被调用 88 次，中心语只出现两种，**都是原因短语**。
补词表前那 44 次「判真」全部来自 `同一控制合并范围变更`——它是原因短语，只是没写成
`同一控制下企业合并`，被旧词表漏掉，于是被误判成新主语（该条不影响结论，因为同分句
原因词就近命中，走 `tgt` 分支）。补词表后判真 0 次。**结论只能说「对存量证据的极性结果
无影响」，不能说「判据从未触发」；判据是否承重由 38 条反例证明，不由回放证明。**

### 1.2 B 项：父输入栏目改「带状态返回 + 目标行绑定 + 期间语义类」

Codex 三条实测：

1. 同页有两个相同金额时，`column_of_amount` 取第一个，可能取到别的行；
2. 登记列头「本期发生额」与原件列头「本期数」被判为不同列，误拒；
3. 扫描页（无文本层）应记「待回读」，不是「不可解」。

改法：`column_of_amount_ex()` 返回 `(列头, 金额, 状态)`，状态五态
`OK / NO_WORDS / NO_AMOUNT / AMBIGUOUS / NO_COLUMN`；`label` 参数把金额**绑定到目标行**
（词坐标 + 指标名同行），同页重复金额记 `AMBIGUOUS` 而不是取第一个；
`cols_equivalent()` 先按**期间语义类**比对（`PRIOR_YEAR_SAME / YEAR_OPEN / PERIOD_END / CURRENT`），
再退回子串，「本期发生额 vs 本期数」归同一类；`NO_WORDS` 记
`PARENT_COLUMN_NEEDS_REREAD`（待回读），不再与「不可解」混为一谈。
C37 注入链由 29 环扩到 **35 环**，新增 6 环正是上述三条：`real_column_needs_reread`、
`real_column_ambiguous`、`duplicate_amount_ambiguous`、`duplicate_amount_row_bound`、
`column_synonym_ok`、`column_antonym_rejected`。

### 1.3 C 项：证据标签要「数量」、SELF_PAGE 要「目标行」、币种要「受控映射」

- `evidence_label` 原先只要 20 字内有数字就放行，于是「见第12页附表说明」里的 12 冒充金额。
  现在要求「标签 + 20 字内**数量**」（带单位或带小数），且该片段不得命中页码/表号
  正则（`_RE_PAGE_REF`），否则记 `REVIEW_LITERAL_NUMBER_IS_PAGE_REF`。
- `SELF_PAGE` 原先取「该金额在原件里最早出现的页」，页眉重复金额会让第 1 页抢走第 2 页
  的真实表格行。现在改为**目标行定位**：词坐标 → 指标名同行 → 该金额 → 列头；
  无词坐标时退回「同页同时出现指标名与该金额」。`NO_AMOUNT / AMBIGUOUS / NO_COLUMN`
  各自有拒绝原因。
- `currency='CNY'` 遇「记账本位币：人民币」被拒属误拒。新增 `CURRENCY_ALIASES`
  受控映射（CNY/HKD/USD 各自一组同义写法），只在组内互认，不做模糊匹配。

### 1.4 D 项：裁决清单自身也受检

上一轮新增 `ruling_scope.csv` 挡住「把 key 和 ruled_key 一起改写」，但 Codex 指出：
**清单里的 `ruling_file_sha256` 改成 64 个 0 照样生效**——清单本身可被改写，等于授权范围可被改写。

新增 `scope_row_ok(section, ent)`：清单行的 `ruling_file` 必须存在、`ruling_file_sha256`
必须与文件实算一致（`RULING_SCOPE_FILE_UNBOUND / _MISSING / _HASH_MISMATCH`），
且须与登记条目自报的裁决文件/哈希一致（`RULING_SCOPE_FILE_DISAGREES`）。
C14 注入由 10 种增至 **13 种**：新增 `scope_file_sha_disagrees`（登记条目与清单不一致）、
`scope_row_hash_tampered`（清单行哈希被改）、`scope_allowed_key_narrowed`（见下）。

**关于「换成另一个已登记 section」**：真实清单只有 1 个 section，这个攻击在真实数据上
构造不出来——换了 section，裁决行文本就对不上，会先被 `RULING_SECTION_MISMATCH` 拦下，
测不到白名单本身。本轮改为直接改清单内容：把该 section 的 `allowed_key` 换成**同公司
另一个已登记字段**，再单独调 `ruling_gap`，必须返回 `RULING_KEY_NOT_IN_SCOPE`。
这在效果上等价于「允许范围被换成了别的条目」，且不依赖自报字段。

### 1.5 E 项：窗口规则下沉，远距离拼接与页脚载体都不算覆盖

Codex 两条实测：把维度载体词放在 501 字之外仍算同窗口；页脚写「分季度见附表」也算覆盖。
上一轮的窗口规则只活在 `verify_v5._dim_window` 里，`scope_dims()` 用的是另一套三词检查。

本轮把规则**下沉到 `parent_verify.dim_window_ok()`**，`scope_dims()` 与自检共用同一份：
三词（指标名 + 该行具体期间 + 维度载体）跨度 ≤ `_MAX_DIM_SPAN = 160`，
且载体词所在句不得是注释/页脚（`注：/附注/脚注/见附表/附表见/页脚/见附录/详见`）。
C38 注入由 12 种增至 **14 种**，新增 `rejected_quote_marker_too_far`、
`rejected_quote_footnote_marker`。

### 1.6 F 项：抽样键集变更的退出归因

Codex 实测：`sampling_keys_diff.csv` 把 `SH:600060|FIN.NPDEDT.SQ|20260630` 的退出原因
写成「不再命中判据」，但该键**仍满足** `_r6_pred`，实际退出原因是排序/名额截取。
另外汇报写「新增 600143 两父数均定位」，而字段 `parent_amount_located` 实为 `ONE`。

改法：

- 入选判据从抽样循环里的匿名 lambda 提为**具名谓词**（`_pred_r1` … `_pred_r10`、`_r6_pred`），
  抽样与 diff 共用同一份——上一轮的教训「阈值只能写在一处」在这里同样适用。
- `REMOVED` 必须归到四类之一：`LEDGER_KEY_GONE`（台账无该键）/ `PREDICATE_FALSE`
  （键在台账但判据不再成立）/ `RANK_CUT`（判据成立但被同公司去重、候选池上限 14、

### 1.1 A 项：极性「结构性新主语」

裁决给的绕过：

```

```

修前把 `100.00` 承接成「ERRATA 肯定」——因为同一分句里出现原因词，后续金额默认继承主语。
修前两轮的做法是**扩充报表项目词表**（`_RE_OTHER_ITEM`），这是无底洞：换个词表外的项目就又漏。

本轮改判据：**金额左侧紧跟片段以名词收尾即为新主语**。

- 取金额起始位置左侧 10 字窗口；
- 命中受影响权益项目词（`未分配利润`/`所有者权益合计` 等）→ 不是新主语，继续承接；
- 以动词/量词/标点/数字收尾（`为`/`计`/`影响`/`元`/`，`/`\d`）→ 不是新主语；
- 剥掉「其中/该/上述/本期/元/数字」等填充后**仍余 ≥2 字** → 判为新主语，不承接前一分句。

反例集 30 → **33 条**，新增：

| 反例 | 修前 | 修后 |

| ⑭ 词表**内**项目切换（`其中营业收入100.00元`） | `set()` | `set()`（守护，防止改判过头） |
| ⑮ 权益项目续写（`对所有者权益合计影响100.00元`） | — | 仍 `scoped=ERRATA`（守护，权益项目不算新主语） |

### 1.2 B 项：极性 —— 本轮重做

第八轮点名了一处**真实误放行**，以及五条内存反例。

**真实误放行。** 三协电机 `BJ:920100`、文档 `DOC-E2BDEAB4F6274B6E`、原 PDF 第 135 页：

> `□会计政策变更 √会计差错更正 □其他原因 □不适用`

V7 的 `option_group()` 对**每个符号**同时看左右两侧标签。因为符号写在标签**前面**，
每个符号的左侧恰好是**上一个选项**的标签，于是「左 ≠ 右」被当成歧义，整行判成
`conflict=ERRATA,POLICY_CHANGE`；`analyse()` 随后按歧义处理，同时写入
`excluded` 与 `affirmed`，而 `judge()` 只在「本行必需维度冲突」时阻断——
POLICY_CHANGE 不是必需维度，于是这行以 `excluded=ERRATA` 一路放行。
该文档供给的 **15 条重述差异全部为 `RESOLVED_SCOPE_COVERED`**。

**修法：版面整体求解。** 不再逐符号混判，而是把整组按两种版面各解一遍：

| 版面 | 取标签的一侧 | 例 |
|---|---|---|
| `after`（符号在前） | 符号右侧 | `√会计差错更正 □其他原因` |
| `before`（符号在后） | 符号左侧 | `适用√ 不适用□` |

每种解法都要求「每个符号都能解出标签」且「标签互不重复」（同一选项被两个符号认领即不成立）。
两种版面都能自洽且结论不同，才判真歧义。

结果：

```
□会计政策变更 √会计差错更正 □其他原因 □不适用
  → excluded=POLICY_CHANGE | affirmed=ERRATA | conflict=-
```

**处置结果。** 该文档 15 条不再解除，全部转 `UNRESOLVED_EVIDENCE_CONTRADICTS`，
并新增 `evidence_conflicts.csv` 逐行登记上游 `verdict` 与原文极性的冲突及其传播范围
（该文档在 B 中供给 15 个元数据槽，全部转冲突；`cell_diff` / `key_diff` /
`extra_meta_diff` / `restricted_claims` 均未引用该文档，传播到此为止）。

**五条反例。** 全部纳入 `polarity_cases.py`，生产与自检共用同一份期望值：

| # | 输入 | 期望 |
|---|---|---|

   第十五轮只堵住「一侧解析出、另一侧写着期间线索却解不出」这一种，**不是全量覆盖**。
