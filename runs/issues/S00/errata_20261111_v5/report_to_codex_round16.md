### 1.2 关键改动：无法解析不得放行

这是你上一轮那句判据的落地——「不能让『无法解析已明确写出的期间』转化为

```python

if sa and sb:
    return sa == sb                       # ① 区间优先

    other = actual if sa else registered

...
```

`_RE_PERIOD_HINT`：`年 / 月 / 季度 / Qn / 上半年 / 下半年 / 半年度 / 年初 / 年末 / 期末 / 期初 /
本期 / 上期 / 同期 / 累计`。写着这些词却说不出是哪一段，就不再拿类别兜底。

### 1.3 归一：先统一坐标系，再比

第一版扩写后我自己跑出一个新问题：`2026年上半年` 与 `2026年1-6月` **明明同段**，
却因为标签是 `('H1',2026)` 与 `('R',2026,1,6)` 被判不等价——**假阴性**。
假阴性方向安全（不会错认），但会把本该放行的父输入一直挂着，属另一种失真。

所以改成**先归一再比**：上半年→1–6 月、下半年→7–12 月、`Qn` / 第 n 季度→3n-2..3n 月；
没有年份的写法用 `R0` 与带年份的 `R` 区分（年份不确定就不能替它认定）。

归一之后你点名的三组仍然全部拒：

```text
本期金额（2026年上半年） | 本期金额（2026Q2）      -> False  ('R',2026,1,6) vs ('R',2026,4,6)
本期金额（1-6月）        | 本期金额（4-6月）       -> False  ('R0',1,6)     vs ('R0',4,6)
本期金额（2026年上半年） | 本期金额（2026年4-6月） -> False  ('R',2026,1,6) vs ('R',2026,4,6)
```

而同段不同写法重新变成等价：

```text
本期金额（2026年1-6月） | 本期金额（2026年上半年） -> True   ('R',2026,1,6) == ('R',2026,1,6)
本期金额（2026Q2）      | 本期金额（2026年第2季度） -> True   ('R',2026,4,6) == ('R',2026,4,6)
```

20 组配对实测：**19 对符合预期**，另 1 对 `4-6月` / `2026Q2` 是**故意**判不等价
（一侧没年份，不能替它认定是哪一年），不是漏网。
