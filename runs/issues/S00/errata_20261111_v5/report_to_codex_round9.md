## 1. B 项：三协电机真实误放行 —— 已修，15 条已重开

### 1.1 根因（与你第八轮的定位一致）

`option_group()` 对**每个符号**同时看左右两侧标签。符号写在标签**前面**时，每个符号的
左侧恰好是**上一个选项**的标签，「左 ≠ 右」就被判成歧义，整行 `conflict=ERRATA,POLICY_CHANGE`；
`analyse()` 按歧义同时写 `excluded` 与 `affirmed`，而 `judge()` 只在「本行必需维度冲突」时阻断，
POLICY_CHANGE 不是必需维度 → 以 `excluded=ERRATA` 放行。

### 1.2 修法

改为**版面整体求解**：两种版面（`after` 符号在前 / `before` 符号在后）各解一遍，
要求「每个符号都能解出标签」且「标签互不重复」，取能自洽的那一种；两种都自洽且结论不同才算真歧义。

```
□会计政策变更 √会计差错更正 □其他原因 □不适用
  → excluded=POLICY_CHANGE | affirmed=ERRATA | conflict=-
前期差错更正适用√不适用□   → affirmed=ERRATA          （后置符号，√ 打在「适用」上）
前期差错更正□适用√不适用，本期发生差错更正100.00元 → conflict=ERRATA（勾选与叙述冲突）
```

### 1.3 处置

- `DOC-E2BDEAB4F6274B6E` 的 15 条重述差异全部转 `UNRESOLVED_EVIDENCE_CONTRADICTS`；
- 新增 **`evidence_conflicts.csv`**（15 行），逐行登记：上游 `verdict` / `method` / `source_page`、
  原文极性、`rows_in_document`、传播范围、修正动作；
- 传播范围已核：该文档在 B 中供给 15 个元数据槽，`cell_diff` / `key_diff` /
  `extra_meta_diff` / `restricted_claims` 均未引用它，传播到此为止；
- **未改上游 `results.csv`**（属 S02 动作），故这 15 行在修正前一律不得按「否」解除。

### 1.4 顺带查出的两个会污染结论的缺陷

1. **半角逗号无条件切分**：`-160,517.06元` 被切成 `-160` 与 `517.06元`，
   金额句丢失非零证据 → `*ST九鼎`、`派斯林` 各 4 条、共 **8 条**事件确认从
   `PENDING_CONFIRMED_EVENT_FIELD_OPEN` 掉到 `PENDING_CONFIRMED_UNSUPPORTED`。
   改为「全角逗号一律切，半角逗号仅在不是千分位时切」，8 条已恢复。
2. **勾选组跨标题误绑**：`（四）审批程序及其他说明 √适用□不适用` 讲的是审批程序，
   却被绑到上一节差错更正主语。改为「标题行换题即断开主语承接」。
