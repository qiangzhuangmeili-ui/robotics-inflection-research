## 3. 三主题对比与可用结论边界

1. **T01 核心零部件**：上游通用/专用设备增加值增速在 2026 年逐期抬升，工业机器人累计产量增速 28%→29.1%，与该主题的景气方向一致；但池内 M01 改善占比与中位数反映的是**公司自身营收**，二者不可互相替代。
2. **T02 装备集成与整机应用**：专用设备增加值加速最明显（4.3%→8.2%→9.5%），工业机器人产量增速稳定；服务机器人累计增速 16.1%→11.9%→7.9% 连续回落、9 月单月转负，是该主题最需要警惕的分化信号。
3. **T03 跨界制造与上游材料**：汽车制造业增加值由 11.5% 降至 7.3%、电气机械 9.2%→7.1%，价格端 PPI 却由 -2.6% 转为 +2.3%。该主题 401 家中多数并非机器人主业，**行业景气不能外推为公司机器人收入**，本主题只保留结构性对照，不产出公司级结论。

## 4. 限制（摘要，完整见 industry_limits.md）

- 申万二级 != NBS 国民经济行业分类；`routing_group` 仅为检索线索，非已核实机器人业务分类。
- PPI != 企业实际售价；PMI 为环比扩散指数；工业增加值覆盖规模以上企业。
- 行业产量/景气 != 单一公司机器人真实收入（T03 尤其显著）。
- H1 与 9M 严格分层，禁止跨期合并；9M 样本显著小于 H1，波动更大。
- 扣非净利润 != 归母净利润 != NBS 工业利润；基期 <= 0 不计常规同比。
- 幸存者偏差：概念池 -> 质量门槛 -> 主线，逐层收窄。
- `PPI_SUBINDUSTRY_ROBOT_SPECIFIC`、`NBS_ROBOT_INDUSTRY_VA` 保持 `UNKNOWN`。
