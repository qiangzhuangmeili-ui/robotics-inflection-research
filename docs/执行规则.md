# 新执行规则 v1

整理日2026-10-25；研究信息截止日沿用2026-10-24。日后更新需另写版本和截止日，不悄悄引入新公告。候选1054家只来自既有概念导出，非全市场完整机器人企业名单。

## 粗筛只回答四件事

1. 是哪一家上市公司或并表子公司？参股、自用和集团外业务分开。
2. 具体机器人产品/专用部件/收费服务是什么？通用电机、通用芯片和客户名单不能自动证明机器人供货。
3. 官方原文能否定位？优先2025年报主营和产品章节，必要时补截止日内2026中报、正式IR。不要粗筛就查完十年。
4. ADVANCE：有可定位的对外机器人业务或机器人用途供应事实，可进入细筛候选；HOLD：来源缺失、用途/主体未明、仅研发样机送样储备等尚不足商业事实；DEFER：在列明检查文档和时间范围内，没有可核实的对外业务，仅泛概念/自用/非并表线索，验收后延后观察。DEFER不是永久剔除，记录重开触发条件。资料失败一律不能DEFER。

每家公司通常1—2条足以回答问题的原文。数量不是质量门槛；关键是能回到原文。检索预算约10—15分钟，预算只限制搜索时间，不以赶时间牺牲核读质量。

## 细筛与拐点

按产品、主体和发生时间拆行。研发/样机/送样/小批/批量交付依据分别记录；订单、产能、合作协议不自动变成批量收入。服务收费不强行换算设备交付阶段。沿用archive/robotics_taxonomy.json作为术语表，所有非UNKNOWN标签需原文证据。

金额、单位、报告期、分母、并表范围必须明确；混合类别不全当机器人收入。缺失留空并记录原因，不填0。预测与已实现分开。2025年报内的2026事实不能回填2025。

财务先取2023—2025年度和2025/2026H1同口径，最新已披露2026三季报仅作后续补充；年初累计不能同单季度比较。先核上市日期、财报更正和合并范围；62家本地缺财务也保留，不因缺失淘汰。当前数据缺披露日期/PIT版本，不做历史回测。

拐点须区分产业变化和公司受益：产品交付/收费事实、机器人相关收入与毛利质量、扣非/现金回款、存货应收和扩产质量，以及至少两期可比数据。行业量增不能证明每家公司获益。无法单列机器人收入时明确盈利归因限制。没有统一增速阈值能自动证明拐点；记录替代解释与未来可推翻信号。

估值在业务、财务、行业核验之后，使用同日价格和清楚的情景假设；不把规划产能或远期市场规模当已实现利润。


## 原文归档和重复利用

统一按[资料保存分级规则 v1.1](资料保存分级规则.md)执行：L1为全池来源索引，L2为实际用于研究的原件归档，L3为关键结论证据链。具体操作见[Google Drive资料归档流程](Google%20Drive资料归档流程.md)。data/document_registry.csv以document_id登记真实Drive URL、file ID、版本、原始官方URL、报告期、披露日期、归档与AI访问状态。

必须先查重，再尝试官方源下载与Drive上传。只有真实取得PDF二进制、上传成功并回读核验后才可写入已归档状态。网页可读不等于文件已下载，链接存在不等于Drive里有文件。自动下载/上传失败时记录具体错误、已尝试入口和目标文件夹，再提出精确人工任务；本地设备离线也要明示，不能把自动化失败推给用户而不说明原因。

同一document_id可被不同包和不同证据引用。归档状态和AI读取状态分开填写；只有AI读到完整原文并核对指定物理页，才标AI_READ_CONFIRMED。关键结论还需记录页码、短引文、主体、时间和事实/计划性质。Drive权限保持受限。

本机sources/inbox可暂存下载和AI读取文件。仅在Drive原件已上传并能打开、身份/版本和索引核对完成后按需清理重复缓存，不删唯一原件。更正报告保留历史版并另记ID。
