# 分组如何得到

data/group_summary.csv为10组计数，完整公司名单在data/company_master.csv，分派名单在每个包assignment.csv。分组仅为了同类材料一起找，提高效率，不能据此认定机器人公司。

规则有先后次序：已采用标签优先，按VC07整机→VC08集成→VC09服务→VC03驱动→VC02传动→VC04感知→VC05/06控制软件→VC01材料确定主线索组。未采用公司先按执行器、减速器、传感/视觉概念，再按驱动、医疗消费、软件通信、装备、材料、汽车电子行业关键词；最后人形概念和宽泛概念。第一命中作主组；原概念和行业全保留便于人工改派。

多概念公司只分配一次主任务，避免两位AI重复查；细筛阶段按实际业务可另建多产品行。组内按概念数量降序、证券ID排序；概念多只用于检索优先级，不是好公司排名。10家校准每组取1家。53已采用、7待补、10旧样本与984新粗筛互斥，合计1054。

主任务包每家公司唯一。D01_DETAIL为下阶段条件包，有意引用其中45家公司，因此不与主任务包相加计算公司总数。B02_REUSE_REFERENCE的53家是参考索引，不是要求一次研究53家。
